# `medis-front` — Visão Geral

## Papel no ecossistema

Aplicação web em Next.js. Ponto principal de interação de pacientes e administradores.

## Responsabilidades principais

- autenticação
- cadastro e perfil
- consulta de doenças
- execução de triagens
- dashboard geográfico
- interfaces administrativas

## Stack principal

- Next.js 13
- React 18
- TypeScript
- React Query
- Tailwind CSS
- Radix UI
