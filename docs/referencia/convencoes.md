# Convenções de Documentação

## Objetivo

Padronizar crescimento da documentação técnica.

## Convenções iniciais

- arquitetura geral antes de detalhes locais
- páginas orientadas a domínio e responsabilidade
- citar caminhos reais de código quando possível
- separar visão estável de detalhe volátil
- registrar decisões relevantes em ADRs

## Estrutura recomendada por página técnica

1. propósito
2. contexto
3. responsabilidades
4. dependências
5. fluxos
6. pontos de atenção
7. referências para código

## Evolução futura

- convenções de diagramas
- convenções de nomenclatura
- padrão de exemplos HTTP
- política de revisão da documentação
